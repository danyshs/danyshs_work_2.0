# Gmail Sorting Utility

A multi-part utility that

- Analyzes and creates a frequency distribution of all email addresses
- Allows for tagging of those email addresses
- Converts tags into a json that can be appended to an existing GMail rule setup and imported to save the tedium of setting custom rules.
